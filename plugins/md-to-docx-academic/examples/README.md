# Примеры рядом с шаблонами

- `report-template.md` — короткий каркас новой работы.
- `full-report-template.md` — полный справочник по поддерживаемой структуре Markdown и всем типам блоков.
- `report.md` — небольшой заполненный пример с рисунком, таблицей, листингом и списком источников.
- `report-vars.json` — пример данных титульника ФИТ; замените демонстрационные сведения своими.
- `gost-report-vars.json` — пример данных титульника для профиля отчёта ГОСТ 7.32-2017.
- `images/results.png` — демонстрационный рисунок для примеров. Для своей работы используйте собственные изображения и подписи.

Профиль ФИТ распознаёт названия структурных разделов независимо от уровня Markdown. Если заголовок `ОСНОВНАЯ ЧАСТЬ` пропущен, конвертер добавляет его перед первым заголовком второго или третьего уровня после введения.

См. команды запуска и правила Markdown в [README.md](../README.md).
